# coffee-demo-bot

Демо-бот для кав'ярні (клієнт + власник в одному боті). UI українською.

## Змінні Railway (Variables)
- `BOT_TOKEN` — токен нового бота з @BotFather (обов'язково)
- `ADMIN_IDS` — Telegram id власника демо (через кому). Дає кнопку «Режим власника»
- `DEMO_CODE` — (необов'язково) код, за яким `/owner <код>` вмикає режим власника на чужому телефоні
- `SHOP_NAME` — назва кав'ярні (посилання на відгуки задаються по точках у налаштуваннях)
- `DATA_PATH` — шлях до JSON (за замовчуванням /tmp; для збереження між деплоями — Railway Volume)

Демо-база: 60 умовних клієнтів створюється автоматично (позначені як демо).

## Фішки
- **Як завжди** — повтор останнього замовлення одним дотиком + вподобання клієнта (бариста бачить їх у замовленні).
- **Кавовий паспорт + QR** — один екран: QR клієнта (токен, а не вгадуваний код) і прогрес по точках. Бариста сканує камерою → картка клієнта з кнопками «Штамп» / «Погасити». Запасний варіант — 6-значний код. Усі 3 точки за 7 днів = подарунок. Бариста обирає свою точку кнопкою «Змінити точку».
- **Розбір тижня** — найслабший день 11–14 за журналом візитів, акція одним дотиком, планування на 10:30. Щопонеділка о 09:00 приходить власнику сам. У демо журнал заповнений умовними даними.
- **Подарунки за цілі** — паспорт (3 точки за 7 днів) → круасан; 8 штампів → кава «як завжди»; вітальний подарунок. Власник змінює нагороди кнопкою «🎁 Нагороди». У тексті нагороди за штампи `{usual}` підставляє улюблений напій клієнта.
- Меню клієнта: «☕ Замовити» (як завжди / нове / вподобання), «📍 Точки й відгук».
- **Режим бариста** — запрошення одноразовим посиланням («👥 Персонал»). Бариста: скан QR, штампи, видача подарунків, відкриті замовлення, вибір своєї точки. Акції, звіти, нагороди й налаштування — тільки власнику. Замовлення на точку йдуть бариста цієї точки.
- **⚙️ Налаштування власника** — назва закладу, поріг штампів, дні паспорта, список точок, напої й ціни, шаблони акцій, тихі години, час розсилки, Google Maps, тижневий розбір і вітальний подарунок.

## Конструктор замовлення
Точка → напій → молоко → сироп → десерт → час → підтвердження. Доплати показані біля кожної позиції
(«Бананове +25 грн»). Кроки без доступних позицій пропускаються. Ціни — демо-значення; власник змінює їх
у «⚙️ Налаштування» (🥛 Молоко, 🍯 Сиропи, 🍰 Десерти, 🍵 Напої). Бариста й власник відмічають наявність
окремо для кожної точки кнопкою «📦 Наявність». Замовлення для бариста містить усі додатки.

## Захист і бонуси
- Пауза між штампами одному клієнту й денний ліміт (власника не стосується), усе змінюється в налаштуваннях.
- Журнал дій персоналу; у «👥 Персонал» блок «Контроль за 7 днів» (штампи, видані подарунки, заблоковані спроби).
- Запрошення друга: обоє отримують подарунок після першого штампа друга, у запрошувача є ліміт.
- Подарунок на день народження: дата вказується один раз, клієнт має бути в боті N днів.
- Передзамовлення: ліміт активних замовлень на клієнта, кнопка «🚫 Не забрали» для бариста, блокування передзамовлень після N неявок за 30 днів (без штрафу за застарілі замовлення, які просто не закрили).
- Сповіщення власнику про незвичну активність бариста (багато штампів за годину чи подарунків за добу).

## Купони, термін дії, бекап
- Кожен подарунок (штампи, паспорт, запрошення, ДН, акція, «Скучили») — особистий одноразовий купон: картинка з назвою подарунка й QR (`?start=g_<id>`). Бариста сканує → «Видати»; після видачі купон недійсний.
- Подарунки мають термін (`gift_valid_days`, за замовчуванням 60 днів; акційні — `promo_valid_days`, 7). Щодня після 10:00 прострочені зникають, за 3 дні клієнт отримує нагадування.
- Акція не дублюється: однакова акція повторно тому ж клієнту не нараховується.
- Щодня після 03:00 копія бази падає власнику файлом у Telegram і в `backups/` на volume (7 останніх). Вручну: `/backup`. Вимкнути: Налаштування → Захист.

## Замовлення: кава, лимонади, коктейлі
- На першому кроці (якщо на точці є кілька розділів) клієнт відмічає ☕ Кава / 🍋 Лимонад / 🍸 Коктейль — можна кілька.
- Лимонад: смак + крок «з льодом / без льоду». Коктейлі: алкогольні (🔞, потрібне «Мені є 18») і безалкогольні.
- Розділи й ціни редагує власник у «Налаштування → Меню та ціни»; наявність по точках — «📦 Наявність».
- Штамп за покупку рахується від найдешевшої позиції з кави/лимонадів/безалкогольних коктейлів.
- «Як завжди» поки що запам'ятовує лише каву. Підтвердження віку — самодекларація, перевірка за датою народження з Poster — наступний етап.

## Розміри та ціни
- Розміри кави: «Налаштування → Меню та ціни → 📏 Розміри кави» (за замовчуванням S, M, L).
- Напої: `Американо - 55/65/75` (ціни за порядком розмірів) або одна ціна `Еспресо - 45` (тоді крок розміру пропускається).
- Молоко: `Бананове - 20/25/30`; окремі винятки для пари молоко+напій: `Бананове | Лате - 10/15/20`.
- Лимонади й коктейлі без розмірів.
